# BVE Workbench

A modern, visual route-building application for **OpenBVE**, designed to simplify route creation and replace tedious manual `.csv` / `.rw` text editing.

> **Status:** Early Planning & Foundation Phase — looking for OpenBVE route builders, testers, and developers to help shape v0.1!

---

## Why BVE Workbench?
Building routes for OpenBVE traditionally relies on editing raw text files by hand, making track curves, gradients, and object placement slow and error-prone. **BVE Workbench** aims to provide an intuitive visual interface that outputs clean, standard OpenBVE route files.

## v0.1 Roadmap (Planned)
- [ ] **Visual Track Layout:** Place straights, curves, and transition geometry visually instead of calculating offsets manually.
- [ ] **Gradient & Elevation Tools:** Intuitive height and slope controls along the track profile.
- [ ] **Object & Station Placement:** Streamlined placement for `.csv`, `.b3d`, and `.animated` objects, signals, and platforms.
- [ ] **Clean `.csv` Export:** Export standard OpenBVE-compatible route files with built-in syntax validation.
