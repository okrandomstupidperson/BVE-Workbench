# BVE Workbench

**An open-source route editor for OpenBVE, built in C#.**

[GitHub Repo](https://github.com/okrandomstupidperson/BVE-Workbench) | [Join the Discord]([https://discord.gg/Pf2G8wJSCC])

---

## What is this?

Making routes for OpenBVE usually means staring at massive text files or dealing with clunky, outdated tools. **BVE Workbench** is a brand-new, open-source route editor built in C# (.NET) to make route building faster, cleaner, and a lot less painful.

### The Plan
* **Easier `.csv` & `.rw` editing** without constantly fighting raw syntax by hand
* **Fast & lightweight** on modern .NET, even on big routes
* **Built with the community** — shaped by actual route builders and C# devs
